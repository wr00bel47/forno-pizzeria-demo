# FORNO — projekt demonstracyjny pizzerii

To statyczna strona portfolio zbudowana w HTML i CSS, z małym skryptem do mobilnego menu.

## Uruchomienie lokalne
1. Rozpakuj folder `forno_pizzeria`.
2. Otwórz `index.html` w przeglądarce.
3. Do edycji użyj Visual Studio Code.
4. Zmieniaj treść w `index.html`, wygląd w `style.css`.

## Publikacja za darmo na GitHub Pages
1. Utwórz konto na GitHub.
2. Utwórz nowe publiczne repozytorium, np. `forno-pizzeria-demo`.
3. Wgraj `index.html` i `style.css` do głównego katalogu repozytorium.
4. Wejdź w Settings → Pages.
5. W sekcji Build and deployment wybierz Deploy from a branch, branch `main`, folder `/ (root)`, a następnie Save.
6. Po chwili strona będzie dostępna pod adresem w rodzaju `https://TWOJ_LOGIN.github.io/forno-pizzeria-demo/`.

## Ważne
- FORNO, adres, numer telefonu, godziny i ceny są fikcyjne.
- Strona jest demonstracją, nie obsługuje zamówień ani płatności.
- Zdjęcia pobierane są z Unsplash przez zewnętrzne adresy. Przed użyciem w komercyjnym projekcie sprawdź licencję i warunki konkretnego zdjęcia; dla klienta najlepiej użyć zdjęć przekazanych przez niego lub materiałów z potwierdzonymi prawami.
- Fonty są ładowane z Google Fonts; połączenie internetowe jest potrzebne do zdjęć i fontów.
- Strona nie ma formularza zbierającego dane osobowe.
